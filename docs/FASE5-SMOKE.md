# Fase 5 — Smoke documentos / 033

1. Login **odontologo** → paciente con consentimiento de datos + visita borrador (con odontograma/índices opcionales).
2. En la ficha, sección **Documentos / Formulario 033** → **Firmar y generar 033**.
3. Debe aparecer el PDF en la lista → **Descargar PDF** y abrirlo.
4. Verificar que la visita queda `firmada` y el odontograma ya no acepta ediciones.
5. Login **auxiliar**: puede ver/descargar, **no** ve el botón firmar.

Notas: el PDF es un **resumen interno tipo 033**, no el facsímil oficial MSP. Validez de firma electrónica pendiente legal (`docs/CUMPLIMIENTO.md`).

Ver [`docs/DOCUMENTOS.md`](DOCUMENTOS.md).
