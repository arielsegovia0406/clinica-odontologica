# Fase 3 — Smoke índices

1. Login con perfil demo **Odontólogo** o **Auxiliar** (botones en login).
2. Paciente con consentimiento + odontograma con al menos caries/obturado/pérdida.
3. Ficha → **Índices**.
4. Ver C/P/O y CPO-D calculados; **Recalcular desde odontograma**.
5. Completar tabla IHOS (0–3 / 0–1) → **Guardar IHOS**; ver DI-S, CI-S, OHI-S.
6. Opcional: sobrescribir con motivo.

Fuentes: [`docs/INDICES.md`](INDICES.md) (Klein-Palmer/WHO, ceo-d, Greene & Vermillion 1964).
